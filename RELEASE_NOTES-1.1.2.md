# Orden der Generäle 1.1.2 — Free Playtest

A free playtest of a card-driven hex-and-counter wargame set in Stalingrad, 1942.

Companies and battalions, 216 metres per hex, about one hour per round. You command through a hand of orders and a limited pool of command points — not through a perfect plan.

## Download

- `Orden.der.Generale.Setup.1.1.2.exe` — Windows installer

Windows 10/11 x64. Unsigned build; if SmartScreen appears, choose **More info → Run anyway**. Check `SHA256SUMS.txt`.

## Changes in 1.1.2

- Foreign/English product name changed to **Orden der Generäle**.
- Armoured vehicle losses now stay in step with crew/personnel losses.
- Assault-gun fire gets a longer armoured engagement window; infantry fire keeps its shorter window.
- KV-1 corrected to the direct-fire F-34; Pz III N corrected to the direct-fire KwK 37.
- StuG assault guns can use a limited indirect fire mission when stationary, against a known/observed hex, at 60% of normal artillery effect.
- Damage-event previews for corps/army artillery, barrages, Katyusha, incendiaries and air support.
- Refit (补充行动值) limited to once per unit per phase.
- Assault-gun/status UI fixes and the single-slash routing overlay removed.

> This is a free playtest build. Rules, card counts, balance and content may still change. Source code is not included.
