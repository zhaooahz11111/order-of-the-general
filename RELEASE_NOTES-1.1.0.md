## English

First formal release.

### Download

- `Order.of.the.General.Setup.1.1.0.exe` — Windows installer
- `Order.of.the.General.1.1.0.exe` — portable build

### What is in this build

- Three decks: movement, attack and special
- 4 normal + 3 special cards per phase; specials carry into the attack phase
- Shellfire impact badges clear after resolution
- Airdrop: 2 CP, full supply, +20 morale
- Flak umbrella, For the Empire, For the Motherland: 1 CP
- Infiltration move, ZOC-chaining restriction, encirclement supply cut
- Artillery fieldworks damage chance, equipment-loss ranges, HQ/artillery screening
- Left-click attack range / right-click movement range
- Random shuffles, dead-hand redraw, at least one reinforcement special

### Notes

- Windows 10/11 x64
- Unsigned build; SmartScreen may ask for **More info → Run anyway**
- See `SHA256SUMS.txt`
- Freeware; source code is not included
